## NON-NEGOTIABLE ARCHITECTURE PRINCIPLES

1. **Zero Framework / Zero Bundler / Zero Runtime CDN Risk:** Pure HTML5, vanilla CSS/JS, and locally vendored copies of `marked.min.js`, `js/vendor/fflate.min.js`, and `js/vendor/pdf-lib.min.js`. The site must work identically behind institutional firewalls, air-gapped USB drives, `localhost`, and GitHub Pages without `npm install` or external CDN calls.
2. **POSIX Paths & Exact Case Parity:** All image and transcript paths in `data.json` must use `/` forward slashes and match actual on-disk casing byte-for-byte (`IMG_0277.JPG` vs `IMG_20260618_0001.jpg`). Windows is case-insensitive; GitHub Pages runs Linux and fails with `404` on case mismatches.
3. **Anti-Caching Protection for Live Scholarly Edits:** Researchers frequently tweak individual `.md` transcriptions and reload immediately. Embed cache-control `<meta>` headers in every HTML page AND pass `{ cache: "no-store" }` to every dynamic `fetch()`.
4. **Best-of-Both Dual-Mode Loading:**
   - **Over HTTP/HTTPS (GitHub Pages or `launch_server.bat`):** Fetch `data.json` and each `.md` dynamically (`fetch(..., { cache: "no-store" })`) so edits appear instantaneously without rebuilding giant multi-MB JS payloads.
   - **Optional `file://` Fallback:** Support optional `window.__TRANSCRIPTIONS_DATA__` and `window.__TRANSCRIPTIONS_CONTENT__` globals generated by `scripts/build-transcriptions.py` whenever `fetch()` fails under `file://` CORS restrictions; if the fallback bundle is not present on `file://`, display a clear actionable notice pointing the user to `launch_server.bat`.
5. **Single Source of Truth in Documentation:** Keep `README.md` 100% synchronized with the actual files you generate — never leave stale instructions referencing unused script names or wrong file extensions.

## PHASE 2: ZERO-FRICTION LOCAL HTTP SERVER LAUNCHER

Opening modern browser pages directly via `file:///.../transcriptions.html` blocks `fetch("data.json")` due to CORS unless running an offline JS bundle OR serving over `http://127.0.0.1:<port>/`. Ship an effortless double-click Windows + CLI launcher:

### 2.1 Auto-Port Python Helper (`scripts/serve.py`)
Write a zero-dependency stdlib server script anchored to repository root:
1. Resolve `repo_root = os.path.abspath(os.path.join(os.path.dirname(__file__), '..'))` and `os.chdir(repo_root)`.
2. Subclass `SimpleHTTPRequestHandler` (bound to `directory=repo_root`) to emit `Cache-Control: no-store, no-cache, must-revalidate, max-age=0` on local responses so transcription edits show on simple browser refresh (`F5`).
3. Implement `find_free_port(start_port=8000, max_attempts=50)` using `socket.connect_ex(('127.0.0.1', port))` so multiple local preview windows never collide.
4. Bind `ThreadingHTTPServer(('127.0.0.1', port), handler)` for responsive concurrent image + markdown loading.
5. Support optional CLI positional port argument (`python scripts/serve.py 8080`) and `--no-browser` flag (essential for headless automation & smoke testing); otherwise launch `webbrowser.open(f"http://localhost:{port}/")` after a short `0.6s` daemon thread delay.
6. Catch `KeyboardInterrupt` cleanly with zero stack trace noise.

### 2.2 Windows One-Click Launchers (`launch_server.bat` & `start_server.bat`)
Create `launch_server.bat` at repository root:
```bat
@echo off
setlocal
title [COLLECTION_TITLE] - Local Server
cd /d "%~dp0"

where python >nul 2>&1
if %errorlevel%==0 (
    python scripts\serve.py %*
) else (
    where py >nul 2>&1
    if %errorlevel%==0 (
        py -3 scripts\serve.py %*
    ) else (
        echo Python 3 was not found in PATH. Install Python 3 to launch the local archive viewer.
        pause
        exit /b 1
    )
)

if errorlevel 1 (
    echo.
    echo Server exited with an error. Make sure Python 3 is installed and available in PATH.
    pause
)
```
Optionally add `start_server.bat` forwarding via `call "%~dp0launch_server.bat" %*` for intuitive discovery.

## TECHNICAL GOTCHAS (WEB & WINDOWS DEPLOYMENT)

- **Always Anchor Batch Files with `cd /d "%~dp0"`:** Double-clicking a `.bat` via Explorer shortcuts or Admin terminals defaults to `C:\Windows\System32` if `%~dp0` is omitted, causing `scripts\serve.py` not found errors.
- **Pass `--no-browser` in Automated Tests:** Never launch an unattended GUI browser tab during CI or verification scripts.
- **Avoid `innerHTML` Races on Dynamic Events:** Always call `addHeaderIds()` and wire `github-report-btn` / `download-select` AFTER `marked.parse()` writes to the DOM, or use delegated listeners on static parent containers (as in `full.html`).
- **Image Pan/Zoom Viewport Overflow:** Keep `.scan-pane` set to `overflow: hidden` with `user-select: none` on the `<img>` so rapid wheel zoom and mouse-drag panning never select adjacent UI text or expand the grid column.
- **Unicode Line Separators in Offline JS Bundles:** If generating `js/transcriptions-content.js`, escape `\u2028` and `\u2029` inside serialized JSON — ES5/older JS parsers treat raw U+2028/U+2029 inside string literals as unescaped newlines and throw `SyntaxError`.
- **Avoid `String.fromCharCode(...bytes)` on Large Scans:** Spreading a multi-megabyte `Uint8Array` into `String.fromCharCode` throws `RangeError: Maximum call stack size exceeded`; always convert to base64 in `0x8000`-byte chunks.
- **Avoid `html2canvas` for 400+ Page Text PDFs:** Rendering hundreds of folios to `<canvas>` crashes browser tabs; use a hidden print `<iframe>` (`window.print()`) for Transcription `.pdf` and `pdf-lib` `embedJpg()` (no canvas decode) for Manuscript `.pdf`.
- **Use `STORE` (`level: 0`) for JPEG ZIPs:** Compressing already-compressed `.jpg` scans with `DEFLATE` wastes CPU and RAM; always pass `{ level: 0 }` to `fflate.zipSync()` for Manuscript Only `.zip` exports.
